Playwright Runner & Setup Chain playwright.config.ts

Every run executes a deterministic 3-stage project dependency chain: auth-setup signs in once with retry resilience, seed-data verifies baseline dev records without blocking, and browser workers run in fresh contexts. 

// Project dependency chain in playwright.config.ts
projects: [
  { name: 'auth-setup', testMatch: /auth\.setup\.ts/ },
  {
    name: 'seed-data',
    testMatch: /seed-data\.setup\.ts/,
    dependencies: ['auth-setup'],
    use: { storageState: STORAGE_STATE_PATH },
  },
  {
    name: 'chromium',
    dependencies: ['seed-data'],
    use: { storageState: STORAGE_STATE_PATH },
  },
]

End-to-End Ticket-to-Spec Workflow (.agent/skills/create-tests/SKILL.md)

Most Used Daily

Turns a Jira/Linear/GitHub issue and developer PR diff into Test Management cases, a Page Object, and a verified Playwright spec.

Step 01
Read Ticket & PR Diff

Reads ticket description, comments, and developer PR diff to catch undocumented UI changes or feature flags.

Step 02
Probe Live Dev DOM

Inspects the live page on dev to discover stable data-testid, data-qa, and ARIA role locators.

Step 03
Propose 1:1 Steps

Designs happy-path, negative, and edge steps for user approval before writing code (1 TMS step = 1 test).

Step 04
Write POM & Verify

Extends BasePage, writes the spec with tmsCase() & isDevRun(), and runs lint + type-check.

Interactive DOM Locator Self-Healing (.agent/skills/heal-locators/SKILL.md)

Zero Runtime Overhead

Instead of brittle runtime AI calls that slow down CI, locator healing happens interactively in Antigravity with human confirmation.

Step 01
Parse Failure Trace

Extracts the broken selector, Page Object method, and call site from test-results/.

Step 02
Inspect Live Route

Opens the target route and inspects the current accessibility tree and attributes.

Step 03
Score 3 Candidates (0–100)

Proposes 3 scored replacements ordered by data-testid/qa (98) → role (92) → label (85).

Step 04
Patch & Re-Run

Patches the Page Object in src/pages/ after approval and re-runs the spec to confirm green.

export default defineConfig({
  timeout: 60_000,
  expect: { timeout: 10_000 },
  /* Automatic production safety lock */
  grep: context.environment === 'prod' ? /@prod-safe/ : undefined,
  use: {
    baseURL: context.baseURL,
    timezoneId: context.timezoneId,
    trace: 'retain-on-failure',
  },
});

Enterprise BasePage & Helper Toolkit

Built for complex enterprise SPAs

readAllVirtualizedRows() Virtualized DOM

Scrolls bidirectional virtualized tables from top to bottom, indexing every row by data-index so rows unmounted at the top are preserved in order, and verifies the total against "Showing N entries".

fillSecure() Zero Secret Leaks

Wraps password and API token inputs in Fill secure field [Password] with ***REDACTED*** so sensitive credentials never appear in HTML or Allure step logs.

InMemoryTokenClient Hybrid UI + API

Intercepts the SPA's next outgoing network request to borrow its in-memory Bearer token, enabling authenticated GraphQL and REST backend assertions without storing tokens in localStorage.

FileDownloadInspector Deep File Verification

Parses downloaded streams to verify actual exported content: CSV headers/rows, PDF magic bytes (%PDF-), and ZIP/XLSX binary headers (PK\x03\x04).
