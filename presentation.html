The 4-Layer ArgonQA™ Architecture

Product teams only write business-readable Page Objects and Spec files. The underlying Core Engine, Security Brokers, and Agentic Skills work out of the box.

Layer 1 — Business-Readable Spec Layer (tests/e2e/)

Zero raw selectors allowed. 1 TestOps step = 1 Playwright test with tmsCase() traceability and isDevRun() mutation guards.

Layer 2 — Typed Page Object & SLA Engine (src/pages/)

Layer 3 — Resilience & Secret Brokers (src/helpers/)

Includes CredentialProvider (Env/Vault/Doppler), EntitySupplyManager (LIFO cleanup), FileDownloadInspector (PDF/XLSX binary magic-byte checks), and SmartLocatorDiagnostics.

// tests/e2e/smoke/navigation.spec.ts — 100% Selector-Free Spec
import { test } from '../../../src/fixtures/base.fixture';
import { isDevRun } from '../../../src/helpers/environment.helper';

test.describe('Workspace Shell (@smoke @sanity @regression)', () => {
  test('1 — shell loads within 1200ms SLA @prod-safe', async ({
    navigationPage,
  }) => {

    navigationPage,
  }) => {

});

Module 05 // Battle-Tested Production Utilities

Built for Complex Enterprise Web Applications

Out-of-the-box solutions for the 4 hardest problems in enterprise E2E automation: multi-cloud secrets, virtualized data grids, binary file downloads, and hydration timing.

1. Multi-Cloud Secret Broker (CredentialProvider)

Switch between env, HashiCorp Vault, and Doppler via a single environment variable—paired with fillSecure() so secrets are always masked as ***REDACTED*** in logs.

const creds = await CredentialProvider.getCredentials(tenant, env);
await this.fillSecure(this.passwordInput, creds.password, 'SSO Password');
2. Virtualized Grid Reader (readAllVirtualizedRows)

Scrolls AG Grid / TanStack / MUI virtualized tables incrementally, indexing rows by data-index so unmounted top rows are preserved in memory and verified against total row counts.

const rows = await this.readAllVirtualizedRows({
  scrollContainer: this.gridViewport,
  rowLocator: this.gridRow,
  totalCountLocator: this.paginationSummary,
});
3. Binary File Signature Inspector (FileDownloadInspector)

Don't just test that a button triggered a download—verify the actual binary magic bytes (%PDF- header, PK\x03\x04 XLSX/ZIP archive header, or parsed CSV rows) in memory.

const pdfMeta = await FileDownloadInspector.verifyPdfSignature(download);
expect(pdfMeta.byteLength).toBeGreaterThan(1024);

Assert backend HTTP status codes and sub-second frontend interaction budgets in a single deterministic call.
